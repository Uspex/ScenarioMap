# Академия — онлайн-школа программирования

Вымышленный проект для демо scenario-map-kit в режиме **карты по документации**: кода здесь нет,
есть только документация продукта. Карты в `flows/` собраны по ней — каждый шаг ссылается на раздел
документа, а `scan` замечает, когда текст раздела поменялся.

## Что умеет продукт

Студент регистрируется, получает пробный доступ к курсам, оформляет подписку, проходит модули и
получает сертификат. Команда школы — кураторы и поддержка — проверяет проекты и решает спорные случаи.

## Роли

| Роль | Кто это |
|---|---|
| Студент | человек, который учится на платформе |
| Платформа | сайт и личный кабинет школы |
| Платёжный сервис | внешний сервис, который списывает деньги с карты |
| Куратор | преподаватель, который проверяет итоговые проекты |
| Поддержка | сотрудники, которые отвечают на обращения |
